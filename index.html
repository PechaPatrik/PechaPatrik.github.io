I'm a game programming and design student at Digital Arts and Entertainment (Howest). Most of my project work sits in game AI, engine programming, and graphics: a custom C++ engine, a Vulkan renderer, and AI systems built around Behavior Trees, steering behaviors, and flow field pathfinding.

Beyond programming, I've led balance and design coherence across two group projects. When I recreate a game, like my Q*bert build, I playtest it thoroughly. A background in speedrunning means I know how far players will push a system, and knowing the code underneath means I know exactly where it's likely to break.

Flow Field Pathfinding

One pathfinding pass that serves every agent on the map at once, not one at a time.

  • Unity
  • C#
  • AI Programming

An Algorithms 2 research assignment implementing flow field pathfinding: a cost field built from Physics2D overlap checks, an integration field solved with a custom binary min-heap Dijkstra implementation, and a direction field baked from it for agents to follow. Includes four live visualization modes and a build-compatible rendering path using GL lines instead of editor-only Gizmos.
